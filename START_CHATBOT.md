# 🚀 INICIO RÁPIDO - CHATBOT

## Para ejecutar el proyecto con chatbot:

```bash
npm run dev:all
```

Esto abrirá:
- ✅ Frontend: http://localhost:5173
- ✅ Backend Chatbot: http://localhost:3001

## El chatbot aparecerá como un botón flotante azul en la esquina inferior derecha

Haz clic en él y empieza a hacer preguntas sobre las Elecciones 2026!

## Ejemplos de preguntas que puedes hacer:

- "¿Cuándo son las elecciones?"
- "¿Qué hace un miembro de mesa?"
- "¿Cuánto me pagan si soy miembro de mesa?"
- "¿Qué pasa si no asisto como miembro de mesa?"
- "¿Dónde puedo votar?"
- "¿Qué documentos necesito para votar?"
- "¿Quiénes son los candidatos?"

## ⚠️ IMPORTANTE:

El chatbot SOLO responde preguntas sobre las Elecciones 2026 de Perú.
Si preguntas sobre otros temas, te dirá que solo puede ayudarte con temas electorales.
